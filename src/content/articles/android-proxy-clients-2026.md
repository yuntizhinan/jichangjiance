Android 上的代理客户端通常通过系统 VPN 接口接管流量。因此，“点了连接但没网”不一定是机场节点故障，也可能是系统权限、省电限制、私人 DNS 或另一个 VPN 应用造成的冲突。

## 一、Android客户端的选择标准

先看订阅兼容，再看界面：

| 需求 | 更应该关注的能力 |
| --- | --- |
| 扫码或节点链接较多 | 批量导入、分组、快速测试 |
| 机场提供统一订阅 | 远程订阅更新、过期提醒、配置切换 |
| AI与流媒体分地区 | 规则分组、手动选择出口地区 |
| 只让部分应用连接 | 分应用代理或应用绕过 |
| 移动网络经常变化 | 网络切换恢复、后台保活、连接探测 |

v2rayNG 更偏向通用节点和路由管理；Hiddify 更强调多协议订阅与跨平台体验。工具名称不是关键，关键是能否正确读取你的订阅格式，并在当前 Android 版本上稳定保持 VPN 服务。

## 二、安装前先做三项检查

1. **确认下载渠道**：核对应用名称、开发者、包名和版本信息，避免安装同名二次打包应用。
2. **确认系统架构**：较新的手机通常为 arm64，不确定时优先使用适配范围明确的安装包。
3. **删除冲突版本**：如果旧版本来自不同签名渠道，覆盖安装可能失败。先备份配置，再决定是否卸载。

安装完成后，不要立即授予通讯录、短信、存储全部目录等与网络连接无关的权限。

## 三、订阅导入的正确顺序

### 远程订阅

适合机场提供的订阅地址：

1. 复制订阅地址；
2. 在客户端中新建远程配置；
3. 粘贴后立即更新；
4. 查看是否出现节点和代理组；
5. 选择节点，再确认系统 VPN 权限；
6. 首次测试只保留默认路由设置。

### 扫码或剪贴板导入

更适合少量节点。二维码和节点链接可能包含服务器、用户标识和连接密钥，不要把完整截图发到公开平台。

### 导入后没有节点

可能原因包括订阅过期、返回格式与客户端不兼容、订阅转换失败，或链接中混入空格。重新从后台复制，避免使用聊天软件二次转发后的截断链接。

## 四、VPN权限和系统图标代表什么

Android 弹出的 VPN 授权表示该应用可以通过系统接口处理设备网络流量。连接后状态栏通常出现钥匙或 VPN 标记，但这只说明系统通道已经建立，不代表远端节点一定可用。

正确验证应包含三步：

1. 国内网站能否正常打开；
2. 目标网站能否访问；
3. 切换节点后出口地区是否变化。

如果 VPN 图标存在但所有页面都打不开，查看客户端日志里是 DNS 失败、连接超时还是握手失败。

## 五、分应用代理怎么用

分应用模式常见两种逻辑：

- **仅代理所选应用**：适合只让浏览器、AI 或流媒体应用经过节点；
- **绕过所选应用**：适合让银行、地图、外卖等本地应用保持直连。

设置后务必实际打开应用验证。部分应用会调用系统 WebView、浏览器或后台服务，如果只勾选主应用，登录页面仍可能走不同路径。

## 六、省电设置为什么影响连接

部分 Android 系统会在锁屏后限制后台 VPN 服务，表现为：

- 锁屏几分钟后连接断开；
- 切回应用才恢复；
- Wi-Fi 与移动数据切换后卡住；
- 通知栏服务被系统清理。

可以逐项检查：

1. 将客户端电池策略改为“不限制”或允许后台活动；
2. 允许自启动和关联启动；
3. 在最近任务中锁定应用；
4. 保留必要的前台服务通知；
5. 不要同时安装多个自动接管 VPN 的工具。

不建议为了保活关闭全局省电或给所有应用无限后台权限，只针对当前客户端调整即可。

## 七、私人DNS与客户端DNS冲突

Android 的私人 DNS、路由器 DNS 和客户端内部 DNS 可能同时存在。常见现象是节点延迟正常，但域名无法解析，或者部分应用能开、部分应用一直转圈。

排查顺序：

1. 暂时把私人 DNS 调回自动；
2. 客户端使用默认 DNS 配置；
3. 关闭自定义规则和广告过滤；
4. 重新连接并查看解析日志；
5. 确认问题消失后，再逐项恢复设置。

一次只改一个变量，才能确定真正冲突的位置。

## 八、移动网络下的弱网参数

在地铁、校园网和手机热点环境中，丢包和网络切换比带宽不足更常见。不要只追求延迟最低的节点，可以观察：

- 连续使用时是否频繁重连；
- 页面首屏是否稳定；
- 上传图片或文件是否容易中断；
- 从 Wi-Fi 切到移动数据后能否自动恢复；
- 视频拖动后是否需要长时间重新缓冲。

如果某种协议在家庭 Wi-Fi 很快、移动网络却完全不可用，可能是网络环境兼容性问题，应保留另一类节点作为备用。

## 九、Android快速故障表

| 现象 | 优先检查 |
| --- | --- |
| 无法更新订阅 | 链接是否完整、订阅是否过期、配置格式 |
| 连接后没有网络 | DNS、节点握手、另一个VPN应用 |
| 锁屏后断开 | 电池优化、后台活动、前台通知 |
| 只有部分应用失败 | 分应用名单、WebView、规则匹配 |
| 移动数据不能用 | APN、IPv6、UDP兼容与网络切换 |

如果多个设备、多个客户端同时出现全部节点不可用，再查看[机场状态记录](/alerts/)；如果只有当前手机异常，优先处理系统权限和省电策略。
